# Bases4Spaces: Learning Orthonormal Bases for Function Spaces

This repo is based off of the work [Learning Orthonormal Bases for Function Spaces](https://arxiv.org/abs/2605.19959). Here, we take a step further and try to make it more practical, using transformer-based architecture and removing the neural ODE portion of the architecture.


The core concept is simple: we are trying to parameterize a sequence of potentially infinite functions that are orthonormal in the function space.
